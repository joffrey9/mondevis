### 📱 QR code sur la carte finale (ajouté le 02/11)

Le QR code (`https://mondedevis.eu`, 330 px sur 1080 de large) apparaît dès
~19,3 s et reste **~8,7 s** à l'écran : assez pour sortir le 2ᵉ téléphone et
scanner. Il est généré dans `build-p3.py` (`qr_tile`, bibliothèque `qrcode`),
relancé et vérifié : le QR se **décode bien depuis le MP4 final** (donc après
compression H.264).

**Pourquoi un QR et pas un lien cliquable ?** Aucune plateforme n'autorise un
lien cliquable *incrusté dans la vidéo* :

| Plateforme | Lien cliquable dans la vidéo ? | Ce qui marche |
|---|---|---|
| TikTok | ❌ | lien en bio / en description (non cliquable en vidéo) |
| Instagram Reel | ❌ | lien en bio uniquement |
| Facebook Reel | ❌ dans l'image | lien cliquable dans la **description** du post |
| YouTube Shorts | ❌ | pas d'écran de fin sur les Shorts ; lien dans la description |
| YouTube (vidéo classique) | ⚠️ | écrans de fin = uniquement vidéos/playlists/chaîne ; carte « lien externe » réservée au Programme Partenaire |

→ Le **QR code est donc le seul vrai CTA cliquable/actionnable** dans l'image,
valable sur les 4 réseaux. Garder aussi le lien texte en description (Facebook,
YouTube) et en bio (TikTok, Instagram).

> BOUCHE FERMÉE** (`scene-artisan-bouche-fermee.png`, générée le 02/11) **avec
> lip-sync Wav2Lip**. Une image de départ bouche ouverte donnait un rendu « qui
> parle tout seul » et peu réaliste — retour de Jo.

- Image : `output/scene-artisan-bouche-fermee.png`, générée avec Gemini image
  **à partir de l'avatar existant** (`avatar mondedevis final.png`) → même visage.
  Relance : `python3 gen-scene-personnage.py --closed`.
- **Lip-sync** : `lipsync-p3.py` (Wav2Lip, checkpoint GAN) → `output/p3-personnage-lips.mp4`.
  La voix est générée **une seule fois** dans `output/p3-voix.mp3` et réutilisée
  par le montage : c'est ce qui garde la bouche synchro. Le montage lit ensuite
  ces images au lieu de l'image fixe.
- Filigrane du générateur retiré par recadrage de 80 px en bas.
- Montage : zoom lent + **titre et lien en haut de l'image** (zone mur/plafond,
  jamais sur le personnage, dégradé sombre pour la lisibilité) + sous-titres en
  bas, 28 s, −14 LUFS.
- **QR code ajouté le 02/11** : carte blanche `SCANNE POUR OUVRIR` **juste sous
  le smartphone** (≈1,5 cm, sur le mur libre à droite de l'avant-bras, jamais sur
  le personnage), de 19,3 s à la fin → ~8,7 s de scan. Taille 220 px.
  Vérifié : le QR se décode depuis le MP4 final. Cadrage de face : il est posé
  **à gauche du téléphone**, à sa hauteur, dans le fond libre (plus sous l'appareil).
- ⚠️ **Piège corrigé le 02/11** : `mux_audio_with_music` retarde la voix de
  **400 ms** par défaut (`voice_delay_ms=400`). Avec un lip-sync, ça décale la
  bouche d'autant (« les lèvres vont plus vite que le texte »). Le montage passe
  maintenant `voice_delay_ms=0` — vérifié : la voix du MP4 final est à 0 ms de
  `p3-voix.mp3`.
- **Chaîne de production** : `python3 lipsync-p3.py` (voix + bouche) puis
  `python3 build-p3-personnage.py` (montage). Si `output/p3-voix.mp3` change,
  relancer les deux dans cet ordre.
- Réglages : `build-p3-personnage.py` · génération d'images : `gen-scene-personnage.py`.
- Autres prises disponibles : `output/scene-artisan-2.png` et `-3.png`
  (variante 3 = plan large pied en bas, variante 2 = main sur l'écran).

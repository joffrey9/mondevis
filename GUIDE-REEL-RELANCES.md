# 🚀 Guide pas à pas — Publier le Reel + relances FB/IG (avatar vidéo)

> **Vidéo à utiliser** : `mondevis/output/avatar-mondevis-final.mp4` (personnage 6-8 s).
> Format 9:16 → prêt pour Reel/Stories IG + Reels FB.
> **Captions prêtes** : `mondevis/output/PUBLICATION_CAPTION.md`.
> Durée totale : **~20 minutes**.

---

## PARTIE 1 — Publier le Reel Instagram (5 min)

1. **Transfère la vidéo sur ton téléphone** (AirDrop, email à toi-même, ou câble).
   - Fichier : `output/avatar-mondevis-final.mp4`
2. Ouvre **Instagram** → **+** (créer) → **Reel**.
3. Sélectionne la vidéo.
4. Ajoute un texte à l'écran (autocollant « texte ») :
   - `Tes devis en 2 minutes 📐`
5. Ajoute un **autocollant lien** : `mondedevis.eu` (le sticker lien est indispensable pour les comptes < 10k).
6. Colle la **caption courte** (depuis `PUBLICATION_CAPTION.md`) :
   ```
   MonDevis, l'appli qui crée tes devis et factures en 2 minutes ⚡️
   Fini la paperasse, tout depuis ton téléphone 📱
   👉 mondedevis.eu
   ```
7. Ajoute les hashtags en fin de caption :
   ```
   #mondevis #devis #factures #artisan #artisanat #btp #entrepreneur
   ```
8. **Couverture** : choisis une frame avec le personnage bien visible.
9. Partage → **Reel publié** ✅
10. **Dans les 60 premières minutes** : réponds à chaque commentaire (ça booste la distribution).

---

## PARTIE 2 — Publier sur Facebook (5 min)

1. Ouvre la **Page Facebook MonDevis** (@mondedevis).
2. **Créer une publication** → **Photo/Vidéo** → sélectionne la même vidéo.
3. Colle la **caption longue** (depuis `PUBLICATION_CAPTION.md`) :
   ```
   📋 Fini les devis papier qui prennent des heures.

   Avec MonDevis, tu crées tes devis et factures en 2 minutes chrono,
   directement depuis ton téléphone. Tout est en ligne, prêt à signer.

   👉 Rejoins les artisans pros sur mondedevis.eu

   #artisan #devis #factures #mondevis #artisanat #btp #entrepreneur #outilspro #gratuit
   ```
4. Publier ✅
5. **Reel Facebook en plus** (optionnel mais recommandé) : Page → **Reels** → même vidéo, même caption courte que IG.

1. Va sur le profil de l'artisan → **Message**.
2. Envoie **d'abord la vidéo seule** (pièce jointe, sans texte) — ça capte l'œil.
3. Puis envoie le message personnalisé correspondant depuis `dm-relances-avatar.md`.

### Sur Facebook (Messenger ou commentaire)

- Même message via **Messenger** si la Page de l'artisan le permet.

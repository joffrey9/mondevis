## 💬 Réponses prêtes à coller (adapte 1-2 mots au post d'origine)

### Quand quelqu'un demande « quel logiciel pour les devis ? »
```
Ça dépend de ton volume : 1-2 devis par mois, Word suffit. Plus régulier,
un outil te fait gagner un temps fou (TVA auto, mise en page pro, envoi
direct au client).

Perso j'utilise MonDevis : je fais le devis depuis mon téléphone sur le
chantier, 2 minutes chrono, le client le signe en ligne. Si tu veux je te
montre, envoie-moi un message 👍
```

### Quand quelqu'un se plaint « le soir je fais encore ma paperasse »
```
Je compatis 😅 Le soir après le chantier, c'est le pire moment pour sortir
Word. Ce qui m'a sauvé : faire le devis DIRECTEMENT sur le chantier, sur le
téléphone, avant de rentrer. Le client voit le montant tout de suite, ça
évite les allers-retours. Si tu veux je te montre comment je fais (2 min),
message privé 👌
```

### Quand la question Peppol / facture électronique sort (🇧🇪 ça va sortir souvent)
```
⚠️ Depuis le 1er janvier 2026, la facture électronique est obligatoire pour
le B2B en Belgique (réseau Peppol). Si tu factures des entreprises, il faut
t'y mettre. Les outils artisans gèrent ça maintenant — perso j'utilise
MonDevis, ça envoie direct sur Peppol et la TVA belge est automatique
(21/12/6 %). Si tu veux que je te montre, DM 👍
```

### Quand quelqu'un dit « je suis nul avec les outils informatiques »
```
T'inquiète, moi non plus 😄 Si tu sais envoyer un WhatsApp, tu sais te
servir de MonDevis : tout sur le téléphone, rien à installer. L'essai est
gratuit 14 jours sans CB. Je t'accompagne pour la mise en route si tu veux,
message privé 🙏
```

## 🚫 Rappels anti-ban (à relire chaque matin)
- **Jamais de lien** dans un commentaire de groupe (le lien va seulement en DM)
- **Jamais la même réponse collée** dans 2 groupes le même jour (réécris avec
  tes mots, change l'ordre des phrases)
- Max **2-3 participations utiles/jour** dans les groupes
- Si les règles du groupe interdisent la promo → réponds utilement SANS
  mentionner MonDevis, DM seulement si la personne continue la discussion
- Réponds aussi aux autres (postes de chantier, questions sans rapport avec
  les devis) : un profil qui n'est là que pour vendre se repère vite
